Five projects, roughly in order of how proud I am of them. Each one taught me something the last one didn't.

Industry · Springer Capital
Real-Time + Batch Medallion Pipeline

Built a dual-path ELT system: Apache NiFi pulls live data from external APIs and streams it into a bronze layer, while Airflow + dbt run scheduled batch transforms on top — both converging into a ClickHouse gold layer for analytics. Containerized the whole stack with Docker Compose: Postgres for Airflow metadata, Redis for the Celery executor, NiFi for ingestion, ClickHouse for serving.

The part that taught me the most wasn't the happy path — it was debugging a NiFi flow file that silently failed its schema validation on every restart, and learning the hard way that named Docker volumes don't auto-seed the way you'd hope.
